# GeoFlow Patch Plan: Fix Gaps + New Docs & Examples

## Overview

Audit found 6 features documented but missing/broken in code. This plan:
1. Patches all 6 gaps in the source code
2. Creates a `docs/` folder with complete, accurate documentation
3. Creates an `examples/` folder with runnable examples
4. Deletes old docs (`GeoTensor_Spec.md`, `DOCUMENTATION.md`, `geoflow-implementation-plan.md`)

---

## Part 1: Code Patches (6 gaps)

### Patch 1: `.geotensor.resample()` — spatial resolution change (HIGH)

**Problem:** Spec §6 shows `.geotensor.resample(resolution=100)` but method doesn't exist.

**File:** `accessor.py` (add after `reproject`, ~line 187)
- Add `resample(self, resolution=None, method='bilinear')` method
- Implementation: derive target grid from resolution, use rioxarray `reproject_match` with same CRS but different resolution, or rasterio.warp.resample
- Record provenance

### Patch 2: `reproduce()` — full provenance replay (HIGH)

**Problem:** `provenance.py:273` raises `NotImplementedError`.

**File:** `provenance.py` (replace lines 273-276)
- Parse graph nodes (already done)
- Load initial data from first node's `parameters['source']`
- Dispatch each operation by name: `reproject`, `resample_time`, `slice_bbox`, `resample`, `fill`, etc.
- On missing source → raise new `DataNotAvailableError`

**Also:** `core.py` — add `DataNotAvailableError` exception; `__init__.py` — export it.

### Patch 3: `to_dataloader(batch_dim=...)` (MEDIUM)

**Problem:** `ml.py:119` hardcodes batch dim to `dims[0]`.

**File:** `ml.py`
- Add `batch_dim: Optional[str] = None` parameter
- Use in `_GeoTensorDataset` instead of hardcoded `dims[0]`

### Patch 4: `open_stac` parameter alias (MEDIUM)

**Problem:** Code uses `datetime_range` but docs say `datetime`.

**File:** `streaming.py:310`
- Add `datetime` parameter alongside `datetime_range`
- `datetime` takes precedence when both provided

### Patch 5: `NonDifferentiableError` gradient guard (MEDIUM)

**Problem:** Error class defined but never raised.

**Files:** `differentiable.py` + `accessor.py`
- Add `_assert_grad_context()` utility in differentiable.py
- In `accessor.py:reproject()`, if `torch.is_grad_enabled()` and CRS change needed → raise `NonDifferentiableError`

### Patch 6: `fill(method=...)` — respect method param (MEDIUM)

**Problem:** `mask.py:316` accepts method but ignores it.

**File:** `mask.py`
- Map `method` value to `interpolate_na(method=...)` parameter
- If `method='time'`, auto-set `dim='time'`

## Part 2: Documentation (`docs/` folder)

Create `docs/` with this structure:

```
docs/
├── index.md                  # Overview, quick start, installation
├── getting_started.md        # Installation, first GeoTensor, basic ops
├── api_reference.md          # Complete API for every module/method
├── architecture.md           # Architecture diagram, module map, design principles
├── alignment.md              # AlignmentSpec, multi-tensor alignment, examples
├── masking.md                # Mask hierarchy, layers, fill, propagation rules
├── temporal.md               # Time handling, resampling, event sampling
├── units.md                  # Unit registry, unit-safe arithmetic, conversion
├── sampling.md               # Patch sampling strategies, PatchDataset
├── differentiable.md         # Differentiable ops, gradient escape, limitations
├── io_backends.md            # COG, Zarr, NetCDF, STAC, VRT, lazy computation
├── provenance.md             # Provenance graph, export, reproduce, freeze
├── ml_interop.md             # Framework conversions, DataLoader, normalization
├── configuration.md          # Config options, defaults
├── changelog.md              # Version history
└── examples.md               # Index of examples (links to examples/ folder)
```

Each doc file:
- Accurately reflects the ACTUAL code API (not stale spec)
- Includes code snippets that match real function signatures
- Notes known limitations (e.g., reproduce scope, spectral interpolation placeholder)
